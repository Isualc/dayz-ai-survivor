# Taktiken - Gedächtnis von Viktor (Jäger & Wildhüter)

- **Kopfschuss spart Munition:** Auf Infizierte immer auf den Kopf zielen - ein Treffer reicht. Tipp von dem Spieler.
- **Stöcke schnitzen:** Messer in die Hand nehmen, dann zu einem Busch gehen - ergibt Stöcke für Feuerbau. Tipp von dem Spieler.
- **Improvisiertes Messer:** 2x SmallStone → craft "stone_knife" = StoneKnife. SmallStone liegt an Ufern/in Wäldern. Tipp von dem Spieler.
- **Armbrust-Bolt zurückholen:** Nach Armbrust-Schuss die Leiche mit `loot_corpse` absuchen - Bolt liegt bei der Leiche und kann wiederverwendet werden. Tipp von dem Spieler.
- **Notfackel als Feuerstarter:** Roadflares (Notfackeln) können ein Feuer anzünden - kein Streichholz/Feuerzeug nötig. Tipp von dem Spieler (2026-06-12). Roadflares beim Looten immer mitnehmen.
- **Waffe klemmt → Melee:** Wenn eine Schusswaffe glitcht oder nicht reagiert, sofort auf Nahkampfwaffe wechseln. Tipp von dem Spieler (2026-06-12).
- **Magazine entladen:** Magazin in die Hand nehmen → eat (auspacken) gibt die Patronen ins Inventar. Munition dann für passende Waffe nutzen oder weitergeben. Tipp von dem Spieler (2026-06-14).
- **Magazin manuell befüllen:** Magazin aus Waffe nehmen → Magazin in die Hand nehmen → befüllen (Patronen interact) → Magazin zurück in die Waffe. Nötig wenn Waffe "keine Ladung" zeigt obwohl Magazin drin ist. Tipp von dem Spieler (2026-06-14).
